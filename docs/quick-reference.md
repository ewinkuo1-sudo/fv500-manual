## 掃描六步驟

::: tip 標準流程
1. **準備樣品** → 光路桿切「側面埠」、軟體物鏡＝實際物鏡
2. **選擇通道** → 雷射波長 / DM / barrier filter 依染劑設定
3. **XY Repeat** → 低雷射功率對焦、Zoom + Pan 決定構圖
4. **調整訊號** → 雷射功率 → PMT → Offset；開 Hi-Lo 檢查
5. **XY Once** → Scan Size 512、Kalman 3、掃描時不碰桌子
6. **存檔** → File → Save As → .oib，拍一張存一張
:::

## 關鍵參數速查

| 項目 | 建議值 | 上限／備註 |
| --- | --- | --- |
| **PMT 電壓** | **400–600 V** | 絕不超過 800 V |
| **Gain** | 1.0 起 | 盡量不動 |
| **Offset** | 背景剛好變黑 | 過度會截掉弱訊號 |
| **雷射功率** | 5–15 % 起試 | 能低就低 |
| **CONFOCAL APERTURE** | **3**（起始） | 1＝最薄最暗，5＝最厚最亮 |
| **Scan Size** | 512 × 512 | 出圖用 1024 × 1024 |
| **Kalman** | 3 次 | 活細胞用 1–2 次 |
| **Z Step（20X）** | **1.0–1.5 μm** | 60X 油鏡 0.3–0.4 μm |
| **Zoom（20X）** | ≤ 4–5× | 更高請換物鏡 |
| **蓋玻片** | **#1.5（0.17 mm）** | 用錯會失焦 |

## 染劑 → 雷射 → 通道

| 染劑 | 雷射 | DM | 通道／濾片 |
| --- | --- | --- | --- |
| FITC / GFP / Alexa488 | 488 nm | Mirror 或 DM570 | CH1 / BA505-525 |
| TRITC / Cy3 / Alexa546 | **543 nm** | DM570 或 DM630 | CH2 / BA560-600 |
| Cy5 / Alexa647 / TO-PRO-3 | **633 nm** | DM630 | CH2 / BA660IF |
| **DAPI / Hoechst** | ✕ 本機無 UV 雷射 | — | 只能目視螢光 |

**最佳雙標組合：TRITC + Cy5（543 + 633，DM630），串色最少。**

## Hi-Lo LUT 判讀

| 顏色 | 意義 | 處理 |
| --- | --- | --- |
| 🔴 紅 | 飽和，資料遺失 | 降雷射功率 → 降 PMT |
| 🔵 藍 | 值為 0，弱訊號被截掉 | 降低 Offset |
| 灰階 | 正常 | 保持 |

> **定量分析的影像絕對不可以有紅點。**

## 禁止事項

::: danger 絕對不可以
- ❌ 手指觸摸鏡片｜用面紙擦鏡片｜用丙酮等強溶劑
- ❌ 雷射開啟時移除護罩、直視物鏡出光口（Class 3B）
- ❌ 自行拔插光纖／訊號線、調整光路、鬆開固定螺絲
- ❌ 攜帶飲料食物進入儀器室
- ❌ PMT 高壓開啟時打開明視野強光
- ❌ 乾鏡沾油後繼續使用｜浸油放到隔夜才擦
- ❌ 雷射運轉中直接切斷 FV5-PSU
- ❌ 先開軟體再開硬體｜跳過 15 分鐘熱機
- ❌ 未經訓練獨自操作
:::

## 離開前必做

::: warning 五件事
1. 影像已存檔，並**複製到自己的儲存裝置**（實際開一個檔確認可讀）
2. 取下樣品、擦淨物鏡浸油、物鏡轉回低倍
3. PMT 降回低值；更換過的濾片／DM **換回原設定**
4. 依順序關機（或確認交接給 2 小時內的下一位使用者）
5. 登記簿填寫結束時間與任何異常
:::

## 卡住的時候：10 項自我檢查

::: tip 依序確認
1. FV5-PSU 鑰匙 ON、主開關 ON
2. 兩台 HeNe 雷射開啟且熱機滿 15 分鐘
3. IX71 光路切換桿在「側面埠」
4. 軟體選的物鏡＝轉盤上的物鏡
5. 雷射波長與染劑相符
6. DM 與 barrier filter 與染劑相符
7. 目視／明視野確認樣品在焦平面上
8. PMT 400–600 V、雷射功率 ≥ 10%
9. CONFOCAL APERTURE 不在 1（先轉到 3）
10. 換一片**已知會亮的對照樣品**驗證
:::

## 緊急處理

| 狀況 | 立即動作 |
| --- | --- |
| 冒煙、異味、異音 | 切斷 FV5-PSU → 拔牆插 → 通知管理者 |
| 雷射外洩、護罩鬆脫 | 立即關雷射，不要自行修復 |
| 樣品打翻 | 關雷射，拭鏡紙吸除，勿讓液體流入物鏡 |
| 停電 | 復電後等 5 分鐘再依序開機 |
| 軟體當機 | 重開軟體；無效則完全關機再依序開機 |
